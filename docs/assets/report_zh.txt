Sharpshooter 三档真实摩擦 × 三档 context 来源

实际摩擦和 context 来源均为 0.3、1.0、2.0，九格完整保留。其余参数 nominal、无外力、完整动作。正确指对应真实摩擦环境交互得到的 context；错误指持续回放另一摩擦环境的同动作交互历史，实时 tracker 输入保持当前状态。不是只在开局给错 latent，也不是直接输入摩擦数值。每个 target 在实际摩擦下校准 350 步并复位。
三组自身回放和三组此前实际 μ=0.3 的轨迹均精确重现；全部 donor/target context 指纹和 latent 逐位一致。跟踪误差主指标为世界系 MPJPE，局部 MPJPE 一并保留；误差增大表示该指标变差，误差下降表示改善。
这是指定三档的确定性个案测试，不证明连续区间适应性；此前正确 context 在 μ=0.33、0.38 的失败记录仍有效。
