ECHOPolicy Lab

Demo overview

Compare ECHO-PRE and ECHO-N as they follow the same reference motion. Adjust ground friction and the context supplied to ECHO-N to explore how interaction history affects control.

How to use

  1. 1
    Choose a motion

    Select the behavior both humanoids will follow.

  2. 2
    Set friction and context

    Match the context to the environment, or try a mismatch.

  3. 3
    Run and compare

    Watch both policies, inspect tracking errors, then reset to try again.
